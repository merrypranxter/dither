# Merge Instructions

This pack is designed as a repo overlay.

## Safe merge method

1. Download the ZIP.
2. Open the existing `dither` repository folder locally.
3. Unzip this pack into that folder.
4. Review the new files.
5. Commit the expansion pack as one batch.

Suggested commit message:

```text
Add dither shader expansion pack
```

## What this pack should not do

It should not replace the existing README.
It should not delete existing starter files.
It should not flatten the repo structure.
It should not turn dither into generic glitch, generic pixel art, or smooth boring shader dust.

## Suggested next commit after this pack

After merging this pack, the next useful pass would be a real examples pass:

- screenshots
- generated preview images
- animated GIF captures
- side-by-side algorithm comparisons
- test outputs from each p5.js and GLSL template
