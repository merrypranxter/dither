# Textile Dither Shader Prompts

## Ordered loom prompt

```text
Create a repeatable textile pattern using ordered dithering as a loom logic. Treat each dither cell as a woven thread decision. Use a limited palette of 4-6 thread colors. The pattern should show visible grid structure, density changes, and woven warp/weft distortion. Include controls for repeat scale, dither matrix size, thread palette, and weave warp strength.
```

## Cross-stitch prompt

```text
Create a cross-stitch-inspired dither pattern. Convert a soft source field into discrete X-shaped stitch marks using a Bayer threshold map. Use a limited thread palette. Keep every mark countable and crisp. Do not use smooth gradients. Make the output tileable.
```

## Jacquard dither prompt

```text
Create a jacquard-like procedural textile where dither values become binary weave decisions. Use a 4x4 or 8x8 threshold matrix to choose foreground/background thread color. Include a floral, geometric, or abstract field under the dither logic. Make it repeatable and pattern-ready.
```

## Tie-dye quantized prompt

```text
Create a fake tie-dye field, then force it through a dithered limited palette. Preserve swirling radial color movement but replace smooth gradients with crunchy pixel-density transitions. Add optional fabric grain and thread noise.
```
