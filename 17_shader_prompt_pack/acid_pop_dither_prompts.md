# Acid Pop Dither Prompts

Use these when the goal is bright, fun, nasty, maximal dither magic.

## Prompt 01

```text
Generate a maximal acid-pop dither field using visible Bayer threshold structure, hot pink and cyan collisions, acid yellow highlights, toxic green sparks, and deep violet shadows. The image should look like a low-color computer is hallucinating a psychedelic poster with very strict pixel rules.
```

## Prompt 02

```text
Create a bright dithered math-art shader using palette quantization, crunchy dot-density ramps, animated threshold maps, and retro computer color limits. It should be colorful and fun, but every smooth gradient must be converted into deliberate dither texture.
```

## Prompt 03

```text
Make a dithered optical pattern where moire rings, Bayer grids, and neon palette reduction fight for custody of the image. Keep the pattern crisp, high contrast, and visibly algorithmic. No soft airbrush gradients. No generic noise dust.
```

## Prompt 04

```text
Create an early-web-meets-acid-poster dither artwork with indexed colors, GIF-like shimmer, crunchy palette jumps, and visible pixel-density transitions. It should feel like a haunted banner ad became a sacred textile.
```
