# Copilot/Agent Prompt

This document serves as a guide for automated agents or copilots interacting with the repository. It outlines the goals and expectations for generating new files, updating existing content, and maintaining the overall structure.

Agents should:

* Respect the existing directory hierarchy and naming conventions.
* Populate Markdown files with well-structured headings, clear explanations, and illustrative examples.
* Populate JSON files with valid JSON objects or arrays, keeping keys concise and consistent.
* Keep YAML, CSV, and other file formats properly formatted.
* Use the file generation order specified in `file_generation_order.md` when expanding the repo.
* Ensure that contributions are stylistically consistent and free of technical jargon when possible.
