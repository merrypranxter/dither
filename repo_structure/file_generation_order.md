# File Generation Order

When expanding this repository, it is helpful to follow a sensible order of file creation:

1. Start by defining foundational concepts in `00_foundation` to establish common terminology and core principles.
2. Document algorithm families in `01_algorithm_families` to provide a technical backbone for understanding dithering mechanisms.
3. Describe the visual language in `02_visual_language` and color considerations in `03_palette_and_color`.
4. Elaborate on distinct style families in `04_style_families` and how dithering appears across media in `05_materials_and_media`.
5. Provide composition guidelines in `06_composition_grammar` and explore motion in `07_motion_and_animation`.
6. Translate concepts into shader and generative art notes in `08_shader_and_genart_translation`.
7. Develop prompt systems in `09_prompt_system` for AI-generated content.
8. Define drift control guidelines in `10_drift_control` and explore cross-style combinations in `11_cross_style_bridges`.
9. Add machine-readable data in `12_structured_data`.
10. Include examples in `13_examples` and reference materials in `14_reference`.
