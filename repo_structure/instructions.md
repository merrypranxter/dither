# Repository Structure Instructions

This document describes the structure of the dither repository and provides guidance on how to navigate and contribute to it. Each top-level folder corresponds to a major area of the dithering domain. Inside each folder, Markdown files explain specific topics, algorithms, styles, or techniques. JSON and CSV files in the `12_structured_data` directory provide machine-readable specifications, indices, and presets for software tooling.

Contributors should maintain the logical grouping of files and follow the naming conventions described in `naming_conventions.md` when adding new content.
