# Naming Conventions

* Folder names begin with a two-digit prefix to enforce ordering (e.g., `01_algorithm_families`).
* Markdown files use snake_case names ending with `.md` to describe specific topics (e.g., `ordered_dithering.md`).
* JSON files store machine-readable specifications and use lower snake_case names (e.g., `style_spec.json`).
* CSV files are used for tabular comparison data (e.g., `comparison_table.csv`).
* Avoid using spaces or special characters in file and folder names.
* When adding new topics, choose concise and descriptive names that reflect the content.
